# Troubleshooting

The messages below are the ones the tools actually print. Search this page for a few words of
the error. What to do when production misbehaves is [incident-response.md](incident-response.md);
the README keeps the most common ones ([README.md](../README.md#troubleshooting)).

## Install and tooling

| Message                                                                       | Cause                                                                            | Fix                                                                                                                       |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `ERR_PNPM_UNSUPPORTED_ENGINE ... wanted: {"node":"^24.15.0 \|\| >=26.0.0"}`   | Node.js too old (`engineStrict`)                                                 | Install Node 24 (`.nvmrc`): `nvm install 24 && nvm use`, or `fnm use`                                                     |
| pnpm lists an ignored build script of `<pkg>`                                 | A new dependency wants to run an install script                                  | Decide in `allowBuilds` of `pnpm-workspace.yaml`, with the reason ([how-to.md](how-to.md#add-a-dependency))               |
| `ERR_PNPM_NO_MATURE_MATCHING_VERSION ... within the minimumReleaseAge cutoff` | The version was published less than seven days ago                               | Wait, or use the previous version; urgent security fix: a dated `minimumReleaseAgeExclude` entry                          |
| `High-risk trust downgrade for "<pkg>@<version>" (possible package takeover)` | The version was published with weaker evidence than earlier ones (`trustPolicy`) | Use the previous version and check the package's repository for an incident; `trustPolicyExclude` only after review       |
| `ERR_PNPM_OUTDATED_LOCKFILE` (CI, `--frozen-lockfile`)                        | `package.json` changed without updating `pnpm-lock.yaml`                         | Run `pnpm install` locally and commit the lockfile                                                                        |
| `pnpm expo:doctor` reports version mismatches                                 | A dependency outside what the installed Expo SDK expects                         | `EXPO_OFFLINE=1 pnpm --filter mobile exec expo install --fix`; newer SDK patches come through Dependabot after seven days |
| `failed to connect to the docker API`                                         | Docker is not running                                                            | Start Docker Desktop (or the Docker daemon)                                                                               |
| Editor shows old Prisma, API or route types                                   | The TypeScript server cached them                                                | `pnpm --filter mobile types:generate` for typed routes; VS Code: "TypeScript: Restart TS Server"                          |

## The app: development and builds

| Message                                                                                 | Cause                                                                                            | Fix                                                                                                                                                                                       |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "You seem to be offline" on the Android emulator, against the local API                 | The emulator cannot reach the computer's loopback                                                | `adb reverse tcp:3010 tcp:3010` (the API; `tcp:4010` for the e2e build), again after restarting the emulator                                                                              |
| `Invalid app configuration: EXPO_PUBLIC_API_URL…`                                       | The variable is missing, or `http://` outside localhost                                          | `apps/mobile/.env` locally, the EAS environment for builds; HTTPS outside localhost ([releases.md](releases.md#environment-variables))                                                    |
| Android build: `CMAKE_OBJECT_PATH_MAX` warnings, then "CXX compiler … broken" (Windows) | The project's path is too long for the native build                                              | Move the project to a short path (`C:\dev\<app>`), enable Windows long paths, `pnpm install` again                                                                                        |
| Android build on Windows: "manifest 'build.ninja' still dirty after 100 tries"          | pnpm's links confuse ninja on Windows                                                            | The user environment variable `pnpm_config_node_linker=hoisted`, `pnpm install` again ([testing.md](testing.md#end-to-end))                                                               |
| Android build: "A restricted method in java.lang.System has been called"                | A JDK newer than React Native supports                                                           | JDK 17 (`JAVA_HOME`); JDK 24 and later break the native CMake step                                                                                                                        |
| Stale JavaScript, odd Metro errors                                                      | Metro's cache                                                                                    | `pnpm start --clear`                                                                                                                                                                      |
| Native errors after changing dependencies or `apps/mobile/app.config.ts`                | The generated native projects are older than the configuration                                   | `pnpm prebuild`, then `pnpm android` / `pnpm ios`: a new development build                                                                                                                |
| Typed routes errors after adding a route, or `process.env` read as `any`                | Expo's generated types are stale                                                                 | `pnpm --filter mobile types:generate` (also run by `pnpm install`, `pnpm lint`, `pnpm typecheck` and `pnpm start`)                                                                        |
| No EAS project                                                                          | `eas init` not done, or its values not in the app's configuration                                | `eas init`, then `APP.easProjectId` and `APP.owner` in `apps/mobile/app.config.ts`                                                                                                        |
| The app gets 426 "no longer supported" from the API                                     | `MOBILE_MIN_VERSION_*` of the API is above the app's version                                     | Unset it locally; in a deployment, [incident-response.md](incident-response.md#15-installed-apps-refused-as-outdated)                                                                     |
| A Jest test hangs or Jest does not exit                                                 | A missing `await` (RNTL 14 is async) or a timer left running                                     | Await every interaction; [testing.md](testing.md#flaky-tests)                                                                                                                             |
| Push notifications do not arrive                                                        | A simulator, Expo Go, no permission, no EAS project id or no credentials, or push off on the API | A development or release build on a **real device**, permission granted, EAS project id set, FCM and APNs credentials on EAS; `PUSH_ENABLED` on the API (`pnpm --filter api push status`) |
| An emailed link opens the browser instead of the app                                    | The domain does not claim the app yet, or claims another identity                                | [incident-response.md](incident-response.md#18-app-links-open-the-browser)                                                                                                                |

## Database

| Message                                                                              | Cause                                                           | Fix                                                                                                                                     |
| ------------------------------------------------------------------------------------ | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm services:up` or `pnpm db:up`: port is already allocated / bind failed on 5452  | Another PostgreSQL (or another project) uses the port           | Root `.env`: `DB_PORT=5453`, and the same port in `DATABASE_URL` in `apps/api/.env`                                                     |
| `DATABASE_URL is not set: copy apps/api/.env.example to apps/api/.env`               | Integration tests without a configured database                 | Create `apps/api/.env` from the example, or set `DATABASE_URL`                                                                          |
| `The seed creates accounts with public passwords: refusing the database at "<host>"` | `pnpm db:seed` against a database on another machine            | Seed local databases only; for a disposable remote one: `pnpm db:seed --allow-remote-database`                                          |
| `Cannot reach PostgreSQL at localhost:5452 (...). Start it with pnpm db:up`          | Integration tests without a database                            | `pnpm services:up` (or `pnpm db:up`), or point `DATABASE_URL` at a server                                                               |
| `Property '<field>' does not exist` on a Prisma model after a pull                   | The Prisma client is older than the schema                      | `pnpm db:migrate` (applies the new migrations and regenerates)                                                                          |
| `Drift detected: Your database schema is not in sync with your migration history`    | The dev database was changed by hand, or a migration was edited | Never edit applied migrations; for a development database with nothing to keep, reset it: `pnpm --filter api exec prisma migrate reset` |
| `P2002` answered as `409 A record with this value already exists`                    | Unique constraint                                               | Expected behavior; validate earlier or handle the 409 in the app                                                                        |

## Landing

| Message                                                                                             | Cause                                                                                                                                                                                                  | Fix                                                                                                                                              |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Port 4331 is already in use` (`pnpm dev`, `pnpm test:e2e`)                                         | Another landing server: a `pnpm dev` still running, or an earlier preview                                                                                                                              | Stop it (`Ctrl+C` in its terminal); the port is fixed (`strictPort`) so the box of `pnpm dev` and the tests can rely on it                       |
| `pnpm typecheck` in `src/i18n/es.ts`: `Property '<text>' is missing in type ...`                    | A text declared in `messages.ts` is not written in one language                                                                                                                                        | Write it in every dictionary ([how-to.md](how-to.md#change-the-landing))                                                                         |
| `pnpm --filter landing test`: `translates the texts rather than copying English into Spanish` fails | A Spanish text is the English one, copied                                                                                                                                                              | Translate it; a word that is the same in both languages (a product name) belongs in `src/lib/site.ts`, not in the dictionaries                   |
| `PUBLIC_URL must be an origin such as https://example.com, without a path or a trailing slash`      | The landing's build got a URL with a path or a trailing slash                                                                                                                                          | Set the origin only: `PUBLIC_URL=https://example.com`                                                                                            |
| `A page path starts and ends with one slash, such as "/" or "/pricing/"`                            | A page address like `/pricing`                                                                                                                                                                         | Write the page's address in the default language, between slashes: `/pricing/`                                                                   |
| `pnpm perf:check`: `OVER BUDGET  JavaScript ...`                                                    | A script reached the landing's build (a `<script>` in a component, a client island)                                                                                                                    | Remove it, or raise the budget in a reviewed pull request that says why ([how-to.md](how-to.md#change-the-landing))                              |
| `pnpm perf:check`: `REFUSED BY THE CSP  <page>: <what>`                                             | A page or a stylesheet of the landing carries what the web server's Content-Security-Policy refuses in production (an inline script or style, a handler, a file, a form or a font from another origin) | Move it to a file of this origin, or drop it ([how-to.md](how-to.md#change-the-landing)); the preview server sends no CSP, so it only shows here |

## API at runtime

| Message                                                                                                   | Cause                                                                                               | Fix                                                                                                                         |
| --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `Environment variable JWT_ACCESS_SECRET is invalid: ...` (or any other) at boot                           | `apps/api/.env` missing or incomplete                                                               | `cp apps/api/.env.example apps/api/.env`, fill the values ([environment.md](environment.md))                                |
| `Environment variable NODE_ENV is invalid` at boot                                                        | `NODE_ENV` has no default, on purpose                                                               | Set it: `development` in `apps/api/.env`, `production` in images                                                            |
| `Environment variable JWT_ACCESS_SECRET is invalid: must be at least 64 characters: openssl rand -hex 32` | A short or hand-written secret                                                                      | `openssl rand -hex 32`, one value per environment                                                                           |
| `Environment variable TRUST_PROXY is invalid: required in production: ...`                                | Production without the proxy setting                                                                | `TRUST_PROXY=1` behind the web image; the real hop count elsewhere ([security.md](security.md#https))                       |
| `Environment variable JWT_ACCESS_SECRET_PREVIOUS is invalid: must differ from JWT_ACCESS_SECRET`          | A rotation step with both values equal                                                              | Set the old secret as previous, or remove it ([security.md](security.md#secret-rotation))                                   |
| `415 Request bodies must be application/json`                                                             | A form, text or file body                                                                           | Send JSON                                                                                                                   |
| `401 Missing access token`                                                                                | The route needs a signed-in user and no bearer token was sent                                       | Call the API through `api` in the app (it adds the token and renews it)                                                     |
| `403 Cross-origin request refused`                                                                        | A page on another origin made a browser call the API (the app sends no `Origin` and is not refused) | Expected for browsers; a browser client on another origin goes in `CORS_ORIGINS` ([security.md](security.md#csrf-cors-xss)) |
| `429 Too many requests, retry later` while testing                                                        | Rate limit (sign-in: 10 a minute per address tried)                                                 | Wait for `Retry-After`, or restart the API (counters in memory) or flush Redis                                              |
| The landing's dev server: `http proxy error` ... `ECONNREFUSED`                                           | The API is not running, or `API_PROXY_TARGET` names `localhost` while the API listens on 127.0.0.1  | Start the API (`pnpm dev`); use `http://127.0.0.1:<port>`                                                                   |
| `500 An unexpected error occurred`                                                                        | A bug or a dependency failure                                                                       | Find the `X-Request-Id` of the response in the API log: the stack and the origin are there                                  |

## Optional infrastructure, email and observability

| Message                                                                                                           | Cause                                                                                                  | Fix                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| `Environment variable RATE_LIMIT_STORE is invalid: redis requires REDIS_URL` (or `CACHE_STORE`, `REDIS_REQUIRED`) | A Redis-backed feature without a Redis to use                                                          | Set `REDIS_URL`, or go back to the in-process stores ([how-to.md](how-to.md#run-with-or-without-redis))                              |
| `Redis unavailable (redis://...): ... ECONNREFUSED`                                                               | Redis is not running or not reachable                                                                  | `pnpm services:up`; in a deployment, [incident-response.md](incident-response.md#4-redis-unavailable)                                |
| `Redis unavailable ...: WRONGPASS invalid username-password pair`                                                 | The password in `REDIS_URL` is not Redis's                                                             | Locally, `REDIS_PASSWORD` of the root `.env` and the one in `REDIS_URL` must match                                                   |
| `Rate limiting falls back to per-instance counters`                                                               | The shared rate limit store lost Redis                                                                 | Expected while Redis is down; it switches back by itself                                                                             |
| Readiness `"status": "degraded"`                                                                                  | An optional Redis is down                                                                              | Fix Redis; traffic keeps flowing                                                                                                     |
| `Slow query (812 ms): SELECT ...`                                                                                 | A query over `DB_SLOW_QUERY_MS`                                                                        | Add the index the statement needs; raise the threshold only if it is noise                                                           |
| `Environment variable SENTRY_DSN is invalid: must be a Sentry DSN`                                                | Not the DSN (the project's key URL), or a typo                                                         | Copy the DSN from the Sentry project's settings                                                                                      |
| No traces or metrics in the backend                                                                               | Telemetry off (`tracing and metrics off` in the boot line), wrong endpoint, or credentials missing     | `OTEL_EXPORTER_OTLP_ENDPOINT` (locally `http://localhost:4328`) and its headers ([how-to.md](how-to.md#turn-on-tracing-and-metrics)) |
| The Redis specs are skipped in `pnpm test:integration`                                                            | No Redis URL locally (`REDIS_URL` in `apps/api/.env`, or `REDIS_TEST_URL`)                             | `pnpm services:up`, and the URL of the example                                                                                       |
| `Environment variable MAIL_FROM is invalid: required with MAIL_SMTP_URL` (or `APP_ORIGIN`)                        | Email turned on without a sender, or without the origin its links point to                             | Set both in `apps/api/.env`                                                                                                          |
| `Environment variable APP_ORIGIN is invalid: must be https in production (http only on loopback): ...`            | Email on in production with an `http://` origin                                                        | `APP_ORIGIN=https://<the app's link domain>`                                                                                         |
| `Environment variable APP_BASE_PATH is invalid: must be "/" or a path such as /app, without a trailing slash`     | A trailing slash, a relative path or characters to escape                                              | `/app`, the path the app and the web image claim                                                                                     |
| `Environment variable SIGN_UP_ENABLED is invalid: requires MAIL_SMTP_URL: ...`                                    | Public sign-up turned on without email: its link could never be sent                                   | Configure email, or leave sign-up off                                                                                                |
| No message in Mailpit (http://localhost:8045)                                                                     | Email off (`email off` in the boot line), Mailpit not running, or `MAIL_SMTP_URL` on another port      | `MAIL_SMTP_URL=smtp://localhost:1045` (the root `.env`'s ports), `pnpm services:up`                                                  |
| `Could not send <kind> message <id> (attempt n): connection; retrying in <s> s`                                   | The SMTP server is unreachable (locally: Mailpit stopped)                                              | `pnpm services:up`; in a deployment, [incident-response.md](incident-response.md#16-email-not-delivered)                             |
| `Could not send ...: tls` in production                                                                           | `MAIL_SMTP_URL` is `smtp://` to a server without STARTTLS: production refuses unencrypted SMTP         | The provider's TLS port (`smtps://...:465`, or STARTTLS on 587)                                                                      |
| `Could not send ...: smtp_5xx_535` or `auth`                                                                      | The provider refused the credentials                                                                   | Rotate them at the provider; percent-encode the password in the URL                                                                  |
| The mail outbox specs are skipped in `pnpm test:integration`                                                      | No Mailpit configured locally (`MAIL_SMTP_URL` in `apps/api/.env`, or `MAIL_TEST_SMTP_URL`)            | `pnpm services:up`, and the URL of the example                                                                                       |
| `Push is off (PUSH_ENABLED unset)` from `push status`                                                             | Push not turned on for that API                                                                        | `PUSH_ENABLED=true` in its environment, then restart or redeploy ([manual](manual.md#59-push-notifications))                         |
| `Push service refused the configuration (InvalidCredentials)` (or `MismatchSenderId`)                             | The EAS project has no valid FCM V1 key or APNs key for that app's identifier                          | `eas credentials` for that profile ([incident-response.md](incident-response.md#19-push-notifications-not-delivered))                |
| `Could not send <kind> notification <id> (attempt n): http_401` (or `http_403`)                                   | Expo refused `EXPO_ACCESS_TOKEN`: revoked, or enhanced push security on without it                     | A new access token at expo.dev/settings/access-tokens in `EXPO_ACCESS_TOKEN`, redeploy                                               |
| `[app] Push unavailable here (a simulator, or no EAS project id)` in the app's log                                | An emulator or a simulator, or a build without `eas init`                                              | A real phone with a development or release build; `eas init` ([manual](manual.md#59-push-notifications))                             |
| `pnpm sast` runs for many minutes                                                                                 | The first run pulls the Semgrep image; after that it scans a copy of the files git tracks or would add | Check Docker's CPU and memory, and large untracked files git does not ignore                                                         |

## Quality gates

| Message                                                                                                          | Cause                                                                          | Fix                                                                                                                                 |
| ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Test `matches the committed openapi/openapi.json (run pnpm contract when this fails)`                            | Controllers or schemas changed after the last export                           | `pnpm contract`, review and commit both generated files                                                                             |
| `apps/mobile/src/api/schema.d.ts does not match openapi/openapi.json`                                            | The app's types are stale                                                      | `pnpm contract`                                                                                                                     |
| A coverage threshold not met (Jest: `coverage threshold for lines`, Vitest: `does not meet global threshold`)    | New code lowered coverage below the floor                                      | Add tests for the new code (error paths, every service method); [testing.md](testing.md#coverage)                                   |
| `OVER BUDGET  <platform> bundle` (or the landing's)                                                              | A bundle grew past its budget                                                  | Find the heavy dependency or the code that could load later; raise the budget only in a reviewed pull request                       |
| CI `Scan for known vulnerabilities` fails with a table of CVEs                                                   | An image contains a package with a fixable HIGH/CRITICAL advisory              | Rebuild (newer base patches), update the base image or the dependency ([security.md](security.md#container-images))                 |
| `N vulnerabilities found ... Severity: ... high` from `pnpm security`                                            | A dependency has a published advisory                                          | Update it; if a dependency pins it, a scoped override ([SECURITY.md](../SECURITY.md#dependencies))                                  |
| `[GITHUB_TOKEN] found GitHub Token` (or another secretlint rule)                                                 | A secret in a file                                                             | Remove it; if it was real, rotate it                                                                                                |
| `<pkg>@<version> (production): license "<id>" is not allowed` from `pnpm deps:check`                             | A dependency's license is outside the policy                                   | Pick another package, or a reviewed exception in `scripts/dependency-policy.json` ([SECURITY.md](../SECURITY.md#dependency-policy)) |
| `pnpm-workspace.yaml: minimumReleaseAge is <n>, the policy requires at least ...`                                | A supply-chain setting was weakened (also `trustPolicy`, `blockExoticSubdeps`) | Restore it; for one urgent fix, a dated `minimumReleaseAgeExclude` entry                                                            |
| `the release-age exemption "<x>" expired on <date>`                                                              | A release-delay exemption reached its expiry date                              | Delete it in `pnpm-workspace.yaml` and `scripts/dependency-policy.json`: the version installs without it by now                     |
| CI `Static analysis (Semgrep)` fails with a rule id                                                              | A pattern of a known vulnerability, or a weakened security setting             | Fix it; a proven false positive: `// nosemgrep: <rule-id> -- reason` ([security.md](security.md#static-analysis))                   |
| CI `Lint GitHub workflows` reports a zizmor finding                                                              | A workflow change broke a rule of ci-cd.md#workflow-security                   | Apply the fix zizmor suggests (permissions, `env:` instead of `${{ }}` in `run:`, a pinned SHA)                                     |
| `Could not start Docker` from `pnpm sast`, `pnpm lint:workflows`, `pnpm iac:check` or `pnpm observability:check` | Docker is not running                                                          | Start Docker; CI runs these checks on every pull request anyway                                                                     |

## Git hooks

| Message                                                   | Cause                                                        | Fix                                                                                                           |
| --------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `subject may not be empty`, `type may not be empty`       | Commit message is not a Conventional Commit                  | `git commit -m "feat(items): ..."` ([commits.md](commits.md))                                                 |
| `Refusing to commit environment files:`                   | A `.env`, `*.env` or `.envrc` file was staged (`git add -f`) | `git restore --staged <file>`                                                                                 |
| `lint-staged prevented an empty git commit`               | The formatter undid the only change                          | Nothing to commit; check the change                                                                           |
| `pre-push: Direct pushes to "main" are not allowed`       | Pushing to `main`                                            | Push a branch and open a pull request (first push of a new repository: `git push --no-verify -u origin main`) |
| `pre-push: Branch "x" must be <type>/<description>`       | Branch name                                                  | `git branch -m feat/<description>` ([branching.md](branching.md))                                             |
| `The command line is too long` (Windows) in a custom hook | Absolute paths overflow the 8191-character limit             | Pass relative paths (the template's hook uses `lint-staged --relative`)                                       |

## End-to-end tests

| Message                                                                 | Cause                                                                               | Fix                                                                                                                                                                                                             |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Executable doesn't exist at ...` / `Please run ... playwright install` | Browser not installed                                                               | `pnpm exec playwright install chromium`                                                                                                                                                                         |
| `Process from config.webServer was not able to start`                   | No build, Docker not running, or ports 4331/8091 in use                             | `pnpm build`, start Docker, stop the process holding the port                                                                                                                                                   |
| `[WebServer] ... Command failed with exit code 1` after the summary     | Playwright stops the servers when the run ends (Windows reports the killed process) | Nothing: the summary (`N passed`) and the exit code are the result                                                                                                                                              |
| Maestro types nothing into a field on the emulator                      | Gboard's stylus tutorial covers the keyboard                                        | `adb shell settings put secure stylus_handwriting_enabled 0`                                                                                                                                                    |
| A Maestro flow fails under an "isn't responding" dialog                 | A slow emulator left a system process (often the launcher) unresponsive             | `adb shell settings put global hide_error_dialogs 1`: Android kills that process instead; a dialog already shown closes once the launcher restarts (the force-stop line of [testing.md](testing.md#end-to-end)) |
| A Maestro flow cannot find the app                                      | The e2e build is not installed, or `APP_ID` names another identifier                | Install the e2e variant ([testing.md](testing.md#end-to-end)); `APP_ID: <identifier>.e2e`                                                                                                                       |
| A test passes alone and fails in the suite                              | Tests depend on each other's data                                                   | Make each test create what it needs                                                                                                                                                                             |

## Web image

| Message                                                                                                                                          | Cause                                                                                                                       | Fix                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The web container exits: `Environment variable APP_ORIGIN is invalid: the public origin of the site, ...`                                        | The image has no `APP_ORIGIN` (it has no default), or one with a path or a trailing slash                                   | Set it to the origin only (`https://app.example.com`); on the server it comes from `APP_DOMAIN` in `server.env` ([environment.md](environment.md#web-variables)) |
| The web container exits: `Environment variable APPLE_TEAM_ID is invalid: ... set together with IOS_BUNDLE_ID` (or another of the app's identity) | Half of a pair, or a value of the wrong shape (a fingerprint in lowercase, without colons)                                  | Set both values of the pair, or neither; the fingerprints in capitals, `AB:CD:…`, comma-separated ([deploy-vps.md](deploy-vps.md#6-the-files-on-the-server))     |
| The web container exits: `Environment variable APP_RELEASE is invalid`                                                                           | `APP_RELEASE` set by hand in `web.env`, with characters the image will not embed in `/release.json`                         | Remove it from `web.env`: the image carries its build's release                                                                                                  |
| The web container exits: `Environment variable NGINX_LOCAL_RESOLVERS is invalid`                                                                 | No nameserver in the container's `/etc/resolv.conf`                                                                         | Run it on a Docker network (Compose's default); nginx looks `API_UPSTREAM` up again every 10 seconds through that nameserver                                     |
| The web container exits: `Environment variable API_UPSTREAM is invalid`                                                                          | `API_UPSTREAM` is not an origin: a path or a trailing slash (`http://api:3000/`), no scheme, a quote                        | Set the API's origin only, such as `http://api:3000` ([environment.md](environment.md#web-variables))                                                            |
| `/api/...` answers `502 {"message":"The API could not be reached"}` while `/healthz` answers 200                                                 | The API is down, or `API_UPSTREAM` names a host nginx cannot resolve (a name only in `/etc/hosts`, `docker run --add-host`) | Start the API; give it a DNS name (a Compose service) ([incident-response.md](incident-response.md#1-api-down))                                                  |
| `/.well-known/apple-app-site-association` or `/.well-known/assetlinks.json` answers 404                                                          | The app's identity is not set on the image (expected until it is)                                                           | Set the pair in `web.env` and recreate `web` ([incident-response.md](incident-response.md#18-app-links-open-the-browser))                                        |

## Smoke test

| Message                                                                                           | Cause                                                                                                                            | Fix                                                                                                                               |
| ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `FAIL  release: release <a>, expected <b>`                                                        | The web image of another build still serves (rollout not finished, the wrong digest, or `APP_RELEASE` set by hand in `web.env`)  | Wait for the rollout, check the deployed digest and `web.env`; roll back if it does not converge ([ci-cd.md](ci-cd.md#rollback))  |
| `FAIL  API through the web server: status 502, expected 404`                                      | The web server cannot reach the API                                                                                              | [incident-response.md](incident-response.md#1-api-down)                                                                           |
| `FAIL  probes not public: status 200, expected 404`                                               | The web server's configuration exposes `/api/health/`                                                                            | Restore the `location` block of `apps/landing/nginx/default.conf.template`; probes stay private                                   |
| `FAIL  landing: links on the build placeholder`                                                   | nginx served the landing without writing `APP_ORIGIN` into it: its `sub_filter` lines were changed or removed                    | Restore `location /` of `apps/landing/nginx/default.conf.template`                                                                |
| `FAIL  share picture: status 404` (or `landing: share picture on another origin`)                 | The image has no `og.png` (the landing's `public/` did not reach it), or its `og:image` was not written with `APP_ORIGIN`        | Restore the landing's copy in `apps/landing/Dockerfile` and `location /` of `apps/landing/nginx/default.conf.template`            |
| `FAIL  the app's links without the app: status 30x, expected 200`                                 | Something redirects `/app/*` (an edge rule, a changed `location`): an emailed link's token rides in the fragment of that address | Remove the redirect; `/app/*` answers the open-in-app page at its own address ([ADR 0008](adr/0008-public-site-and-app-links.md)) |
